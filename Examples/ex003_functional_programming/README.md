# Functional Programming Examples

## Objective

Learn the core principles of Functional Programming in Elixir through practical examples.

## Topics Covered

- Immutable Data
- Pure Functions
- Anonymous Functions
- Closures
- Higher-Order Functions
- Map
- Filter
- Reduce

## Run

```bash
mix run lib/main.ex
```

## Expected Outcome

Understand how Elixir transforms data using functions rather than mutable state.
