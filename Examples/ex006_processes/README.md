# Elixir Processes Examples

## Objective

Learn the basics of Elixir Processes and Message Passing.

## Concepts Covered

- spawn
- self
- send
- receive
- PID
- Mailboxes
- Process Loop
- Timeouts

## Run

```bash
mix run lib/main.ex
```

## Expected Outcome

Understand how Elixir processes communicate using messages and why they are the foundation of OTP and GenServer.
